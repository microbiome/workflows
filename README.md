# workflows

Microbiome workflows

## About

This project builds an open, reproducible workflow that shows how to analyse
a microbiome study that has both **metagenomic** and **metabolomic** data. It
goes from raw data to results.

The project is part of [Bioconductor](https://bioconductor.org) and the
[Bioconductor Microbiome Working Group](https://workinggroups.bioconductor.org/currently-active-working-groups-committees.html#microbiome).

## Get involved

Everyone is welcome to join! You can take part whatever your background or
experience: you can contribute code, data, analysis ideas, reviews or
feedback. To get started, open an
[issue](https://github.com/microbiome/workflows/issues), look through the
[meeting notes](https://github.com/microbiome/workflows/wiki/Meeting-notes),
or reach out through the
[Bioconductor Microbiome Working Group](https://workinggroups.bioconductor.org/currently-active-working-groups-committees.html#microbiome).

## Code of Conduct

Everyone taking part in this project must follow the
[Code of Conduct](CODE_OF_CONDUCT.md), which refers to the
