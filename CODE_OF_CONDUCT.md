# Code of Conduct

This project is part of the [Bioconductor](https://bioconductor.org) project
and is developed within the
[Bioconductor Microbiome Working Group](https://workinggroups.bioconductor.org/currently-active-working-groups-committees.html#microbiome).

All contributors and participants, in every project space (issues, pull
requests, discussions, chats, meetings and events), are expected to follow the
[Bioconductor Code of Conduct](https://bioconductor.org/about/code-of-conduct/).

## Reporting

If you experience or witness behavior that violates the Code of Conduct,
please report it as described in the
[Bioconductor Code of Conduct](https://bioconductor.org/about/code-of-conduct/).
